# 经期记录与预测助手

## 功能特点
- 📝 记录每次经期的开始和结束日期
- 📊 自动计算平均周期和平均经期长度
- 🔮 基于历史数据预测下次经期
- 💾 数据保存在浏览器本地，不会上传
- 📱 响应式设计，支持手机和电脑

## 使用方法
1. 打开 index.html 文件
2. 添加经期记录（开始日期、结束日期）
3. 查看统计数据和预测信息
4. 可以删除或清空所有记录

## 技术栈
- HTML5
- CSS3 (Flexbox/Grid, 动画)
- JavaScript (ES6)
- LocalStorage 数据存储

## 预测算法
- 基于最近一次经期开始日期 + 平均周期天数
- 需要至少2次记录才能进行预测
- 记录越多，预测越准确
